# Treino

App que eu uso para registrar meus treinos de musculação, na hora, entre uma
série e outra. Feito só para mim e para o meu celular.

- Abre já no treino do dia: A, B ou C.
- Uma série se registra com um toque, com a carga da última vez já preenchida.
- Progressão dupla: depois de duas sessões seguidas fechando o topo da faixa de
  repetições, com folga, ele sugere subir a carga. Quem decide sou eu.
- Cronômetro de descanso, registro de desconforto e observação por exercício.
- Funciona sem internet. Os dados ficam guardados no próprio aparelho, e dá
  para salvar um backup em arquivo.
